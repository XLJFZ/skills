# 批判评审规则

先建立图纸版本及审查范围。检查场地回应、功能、体验、流线、尺度、剖面、环境、结构、建造、规范、可达性、图文一致性。逐项标“发现问题/本轮未发现问题/资料不足/不适用”；未发现不等于证明无问题。

| 级别 | 判定 | 处理 |
|---|---|---|
| 致命 | 已有证据表明核心空间不可达、关键逻辑不成立，或明确适用要求下存在生命安全问题 | 暂停受影响定案，列替代与复核 |
| 重大 | 功能冲突、主流线中断、面积严重不闭合等，需改变组织 | 回阶段3—5，复查依赖 |
| 一般 | 局部性能与体验可改进 | 落到具体节点修改 |
| 表达问题 | 标注、图例或图纸间不一致 | 先查是否反映实际设计错误 |

严重程度与证据置信度分开。资料不足时写“潜在重大风险，待核验”，不能判定违反某条规范。每条问题包含位置/版本、证据、影响、修改建议、复核方法、责任状态。先审查AI自己的假设，不为维护上一轮建议而掩饰矛盾。不得以总分掩盖致命问题。
