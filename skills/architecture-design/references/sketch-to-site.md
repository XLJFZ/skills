# 指定草图转绘与边界适配

适用于用户要求“按老师画的路径分割”“照此转绘”等忠实转译任务；不限制用户明确授权的自主方案探索。

1. 锁定参考：多张或一张中的多个变体分开编号。优先采用用户指定者；未指定可先转绘最完整清晰的一张并明示，不拼合变体。核对真实基地轮廓、邻接及方向来源。
2. 原图描线：保留参考裁片，在其上手工描出可辨识路径；每个端点、交会与转折编号。草图无图例时，区分用户明确的路径与尚不能辨认的构造线。不得声称手工近似描线是精确恢复。
3. 映射：记录定位锚点、缩放或分段映射方法。保持图的连接、分支及先后关系；不得把非均匀映射称作原比例复制。真实边界保持不变。
4. 冲突：原路径越界、落入凹口、连接不明时，保留原路径为对照并圈注冲突。未获授权不得移动路径、补绕行或延长到入口；可完成其余明确部分。
5. 分割：先用路径划分剩余区域；未给用途时只编号，不推定展览、教育、后勤或院落。路径带宽无实测时仅为图示，不能当设计宽度。
6. 复核：交付原图描线与基地映射对照；检查新增/丢失边、端点、转折、越界和图例。区分原路径、映射路径、未决冲突和经用户授权调整。输出前实际看图，不能以XML可解析代替视觉复核。

本模式门槛：能明确映射的部分可以交付，冲突部分标未决。关键原意不明且影响整体连接时，只问定位明确的问题，不能直接宣称忠实完成。
