# 模型修改与几何验证

适用于实际编辑三维建筑模型；按本轮构件选择检查，不要求每次重跑整套技术审查。

## 先分清问题

- 将视口明暗异常与实体形状错误分开。屋面看似扭曲时，先检查截面、控制点、面法线与网格平滑，再决定是否重做形体。不能只换显示模式掩盖真缺陷，也不因平滑伪影无依据改方案。
- 锁定输入文件、单位、原点、当前图层和版本；检测用户已改内容。只修改授权对象，另存新版本，保留可回退依据。不要依赖脚本的持久变量或假定活动文档就是上轮文件。

## 先例怎样转成空间与构件

- 明确可借用的是路径、尺度层级、屋脊/山墙/檐口关系，还是确有依据的构造。历史形制、案例实测数据、本轮参数分别登记。
- 屋脊方向按房间、结构及正房/侧翼组织确定，不仅按包围盒最长边自动选择。转角需画清主次脊、高低、交接及排水；不能以互相穿插的屋面称作已解决节点。
- 模数、坡度、折坡曲线、檐口高、结构厚度均需说明来源或标D/H。缺测绘时可作现代转译，不称传统法式复原。当前项目的硬山、悬山或任何特定类型都不是其他项目的默认答案。

## 修改影响不能漏

|改动|最小复核|
|---|---|
|屋顶、脊高、坡度|实际最高点；墙顶/门窗；结构与设备后的净高；主侧屋交接、天沟落水；新增出檐投影与退界|
|楼梯、连桥、平台|从真实门洞逐段到达；地面完成面高差；楼板与井口；必要护边；不得把实心占位核当可用电梯井|
|功能分隔、家具|门洞、净宽与使用空间；噪声、管理及运输联系；实际可用面积，不能靠改标签满足任务书|

尺寸和形体发生变化时，相关旧验证标过期或缩小适用范围。建筑首层未越界不证明屋檐未越界。对象闭合、IsValid或文件可打开均不能证明合规、防水、结构或可使用性。

## 文件与图像都要核

1. 限值从实际几何测量，不仅输出生成参数。检查整体最高点和构件包围盒，防止参数顺序、单位或变换错误；按需检查实体、开口、相交与面积。
2. 图层隔离后，枚举需保存的全部对象（包括隐藏图层），再按明确清单筛选。不要把仅可见对象误导出为完整版本。
3. 重新打开保存文件，核单位、方案对象数与关键构件是否存在，避免只剩场地或背景。保存时的默认图层状态与交付预览对应。
4. 看实际总平、关键剖面或局部和鸟瞰。截图显示模式不证明材质或几何；参数输出、图像和文件之间有矛盾时先纠正再交付。
5. 报告具体改动、验证范围和未决项；“阶段深化”不等于已完成正式工程设计。
