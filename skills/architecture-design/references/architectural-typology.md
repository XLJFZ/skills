# 空间原型的提取和转译

原型是待检验的关系机制，不是文化身份的证明。按“原始材料定位 → 可观察特征 → 抽象关系 → 当代功能 → 空间操作 → 失败条件”转译。

| 原型 | 提取参数（需要资料） | 可探索的博物馆操作 | 风险及反证 |
|---|---|---|---|
| 街巷 | 路径分支、宽窄、界面、入口密度 | 公共主街连接独立展厅 | 穿行干扰安检；检验闭馆路径 |
| 院落 | 围合、开口、进深、可达性 | 院落组织展厅和停留 | 日晒、雨天绕行、面积效率；检验天气分支 |
| 廊道 | 连接对象、遮蔽、视线、节奏 | 受控展廊与室外回游 | 交通面积膨胀、展品曝光；核对面积和光环境 |
| 广场 | 边界、出入口、活动与时间 | 前场或非票务公共客厅 | 空置与排队冲突；分时行为图验证 |
| 空间序列 | 阈限、明暗、转折、压缩释放 | 展览叙事与休息节点 | 强制单线、疲劳和无障碍断裂；检查短回路 |

不根据词语自动配形：院落不必仿古；街巷不等于曲折走廊；地域性不能由屋顶和纹样证明。
