# 空间组织与检查方法

邻接矩阵用“必须直接/宜邻近/可分离/应隔离/未知”，每条注明原因；对称关系与有方向的运输路径分开记录。节点列入口、门禁、垂直交通、展厅、库房、装卸、设备和室外连接。

分别画普通观众、团体、员工、展品/物流、维护、无障碍和紧急疏散路径；同一路径可服务多类人，但要验证时间和管理条件。流线图必须回到平剖面门、楼梯、电梯等真实连接，不能用箭头跨越无门墙体。

平面：核对门口、回转、家具/展柜占用后的净空间；无尺度只能检查拓扑。剖面：标层面、净高、结构及设备占用，检查楼梯、电梯、坡道和屋面连接。环境：展品保护与公共采光分区，气候资料与运行方式缺失时仅提出假设。

面积：净功能面积之和不等于建筑面积。分别列交通、墙体/结构、设备及其他计入项，说明不重复口径；未知系数不自动补。若净毛转换使用系数，必须有来源或标为H并做敏感性比较。验证总额守恒和双重计数。

结构与建造：柱网、跨度、悬挑、荷载类别、设备及展品运输条件互相检查，缺工程依据不作安全结论。用一个主要节点剖面检验材料层次、排水和结构表达是否自洽。
