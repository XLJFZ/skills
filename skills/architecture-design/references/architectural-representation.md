# 建筑表达规则

每张图绑定一个已明确主张和依据：证据图解释材料，问题图解释矛盾，策略图解释空间操作，技术图解释验证。图例区分实测、引用、推断、提案；示意关系图不得伪装成有坐标的总平面。

检查总图、平面、立面、剖面、轴测和透视中的入口、层数、开口、柱位、院落和楼梯一致。未定案部分标探索版本；图像中的额外空间不能自动进入设计记录。

生成图像前写明空间意图、视点、体量关系、关键开口与不得改变的几何约束。生成后对照图纸复核；不一致处修图或标示意。没有图像工具时交付可用表达脚本与绘图说明，不谎称生成图片。展板叙事使用证据→问题→策略→空间→验证→仍存问题。


## 从模型生成平剖面

- 先锁定控制模型、单位、楼层完成面和图纸用途。标明切面坐标/高度、剖视方向、投影方式及纳入对象；切面高度由门窗、楼梯和表达目的决定，不把某个项目的标高设为默认。
- Rhino中用户指定ClippingPlane→Make2D时，使用真实剪切平面和原生Make2D。其他环境选能保留剖切与遮挡关系的方法；若采用等效API，明确方法及其验证依据，不能冒称执行了原生命令。单纯几何截线只能作诊断或剖切线来源，不能代替完整剖面中的剖后可见轮廓。
- 先用一张代表视图验证切除侧、平行投影、遮挡和输出分类，再批量出图。Rhino Make2D需检查截平面交线选项及剖切填充的遮挡效果；在支持剖切填充的着色视图中核对，不假定当前显示模式或上次命令选项正确。命令选项随版本/语言不同，先核实，不用猜测的脚本连续批量执行；未结束时先取消并确认命令已退出。
- 楼层平面区分本层剖切、下层可见部分和上方投影；低层屋顶不应误切成本层墙体。按图纸目的设置参与剪切的对象或分开投影并区别线型；省略的屋顶或环境须说明。楼梯断线、上/下行箭头等是制图整理，不能把整段投影当作已整理完成。
- 输出区分剖切、可见、隐藏/上方投影；按打印比例整理线宽、必要的剖面填充、门窗、楼板洞口、楼梯及标高。隐藏线按用途取舍，不能全开后以杂线掩盖空间。剖切符号的位置与方向须对应实际切面和视点。尺寸从模型测量，不以包围盒补画建筑或以标签替代缺失构件。
- 保留可编辑线稿、图与源模型的对应关系、剪切平面及可复现的视图设置。保存后验证剪切平面仍为正确对象类型，视图能恢复所需剪切；关闭默认视窗剪切不能使交付视图无法复现。原始出线、制图整理和最终图纸的状态分别记录。
- 逐页渲染检查PDF，核比例/比例尺、方向、线宽、裁切、文字和图纸间一致性；同时对照实际模型剖切视图。出线成功不等于符合建筑制图要求，更不证明设计合规。旧图有误时标为停用并给出替代版本，不再混入新图册。

## 彩色图像及交付

- 区分模型原生渲染、着色视口截图和生成式示意图，按实际方式命名。要求彩色时核实际材质/颜色输出，不用线框图代替。
- 复用已有渲染前比较当前控制模型及材质、可见性等影响图像的状态；几何相同本身不足以证明旧图仍一致。说明其对应版本；状态已变化则重出或明确旧图适用范围。
- 用户要PDF或图片时，交付可打开的具体文件并直接展示适量预览；不能只报告已导出或给目录。PDF可独立阅读，图片使用宿主支持的直接展示方式。文件检查与视觉检查均完成后再称交付。
