# 设计方法与迭代

链条示例（条件性，不是事实）：E-01观察显示某处有停留行为 → P-01公共停留与安检排队冲突 → S-01分离自由通行与受控参观 → O-01设置可独立开放前厅和安检侧入口 → V-01在开放/闭馆两种状态追踪路径，检查交叉、回退与值守界面。

问题必须包含具体对象、冲突、时段/状态、影响和可验证目标。将“文化特色”改写为“历史空间研究提取的通行—停留节奏能否形成可识别但不阻塞参观的公共序列”，且先核实研究材料。

每项策略列出失败条件；先以关系图和简化剖面证伪，再投入精细建模。使用低成本方法：纸上路径描绘、面积求和、节点邻接表、剖面高度链、不同开放状态叠图。参数模型仅在参数来源和约束明确时使用；参数变化自动标记相关验证过期。

评审发现问题时回到产生它的最早依赖。修改总图入口需复查场地、安检、无障碍及服务流；更换展览组织需复查面积、展品运输和疏散。没有普适权重或唯一最优原型。
