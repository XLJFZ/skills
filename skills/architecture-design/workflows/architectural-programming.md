# 建筑策划

## 必要输入
任务书已知功能、规模约束及其缺项；核心P-ID。先复用已提供内容，注明版本。缺项按总控规则决定有条件探索范围。

## 可选输入
藏品特点、运营模式、人数时段、运输设备。

## 工作步骤
1. 分解展示、教育、公共服务、收藏研究、办公后勤、设备交通等功能，适用性待确认。
2. 按净/毛口径建面积表；未知写未知，检查求和、重复和总额差异。
3. 建邻接矩阵、公共/半公共/受控/后勤分级；分开访客、员工、展品、维护流线。
4. 用开放/闭馆/布展场景检查门禁及交叉，列依赖与未决条件。

## 输出物
功能表、面积表、邻接矩阵、流线关系图、运营场景表。采用 [对应模板](../templates/area-program.md)；输出之间用E/P/S/O/V ID关联。

## 质量检查
面积有单位和来源；关键漏项、流线交叉和公共性矛盾显露；不默补规划指标。

## 进入下一阶段的条件
基本功能关系可描述可进入阶段4；规模未定只做拓扑概念，不宣称容量适配。不满足时标有条件探索/待确认；用户跳过时记录理由、风险、补验时点，不能标通过。后续新证据可触发回退。
