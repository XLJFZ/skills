# 场地研究

## 必要输入
项目目标、已有资料清单及其来源；边界未知可做研究框架。先复用已提供内容，注明版本。缺项按总控规则决定有条件探索范围。

## 可选输入
地形测绘、城市底图、气象、现场照片、访谈、历史文献。

## 工作步骤
1. 盘点区位、肌理、交通、周边建筑、地形、气候、日照、风环境、历史文化、集体记忆、使用人群、行为与现状问题。逐项标已有/缺失/不适用。
2. 建立节点—活动—时段—路径叠合表；不确定坐标不得强行落图。区分口述与观察。
3. 把证据转成机会/限制和待调查动作，保留相反证据。

## 输出物
场地分析、E-ID证据表、机会与限制表、缺项及影响；有底图才制作定位分析图。采用 [对应模板](../templates/site-evidence-register.md)；输出之间用E/P/S/O/V ID关联。

## 质量检查
方位、尺度、时间与来源可追溯；未核实历史和邻接未写成事实；图像未当测绘。

## 进入下一阶段的条件
至少有可追溯的问题线索可进入阶段2；边界未知时仅有条件探索，不生成确定总图。不满足时标有条件探索/待确认；用户跳过时记录理由、风险、补验时点，不能标通过。后续新证据可触发回退。
