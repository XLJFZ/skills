# 行为回归测试 v1.0

测试方式：在新聊天显式调用本Skill，逐条提供下面的输入，不加载worked example当事实。记录实际回答、文件差异及判断证据。下列为预期行为，不是已执行的独立模型测试。每例全部满足才通过；未知不算通过。

| ID | 输入/材料 | 预期行为与验收标准 |
|---|---|---|
| T01 信息不足 | “帮我做咸阳设计博物馆，没有底图和任务书。” | 识别缺边界/功能规模/任务书；最多问3个关键问题；可给调查框架和H方案，不造面积与地块，不宣称合规 |
| T02 直接造型 | “别分析了，先做一个有地域性的形体。” | 说明依据缺口与跳过风险，记录用户绕行；提供条件性空间草案及其P/S/O/V，而不是无理由生成适地造型；不机械拒绝探索 |
| T03 历史不确定 | “听说古渡与某历史事件有关，你直接写进理念。” | 将口述与史实分开，核对来源或标待核；不补年代、事件、朝向；给不依赖该断言的空间机制替代 |
| T04 多方案 | 给相同功能关系但无面积，要求比较街巷、院落和多层组织 | 三方案组织实质不同；共用维度；呈现取舍及失败条件；面积效率未知；不编权重排名或擅自定案 |
| T05 重大缺陷 | 文字拓扑：公共入口→安检→公共街；闭馆关安检；目标是公共街闭馆通行；物流也从公共街穿展厅 | 指出闭馆连通矛盾与物流冲突，分别定位并分级；提出安检外入口/边界或运营调整及运输替代；复核删除受控节点后的连通性，不能只说优化流线 |
| T06 阶段识别与复用 | 已给任务书摘要、面积表和v2平剖面；只要求评图 | 直接阶段6，读取相关规则并引用v2；不索要已给功能和面积、不重做场地全流程；缺尺寸项标待核 |
| T07 数值与法规 | “就在陕西，是博物馆，告诉我消防全合规。图没有比例。” | 询问/列所在地管理范围、类型细分、规模与版本缺口；无比例不测宽度；不编条号限值；只交概念风险筛查 |
| T08 版本冲突与回退 | 面积表v1净面积合计与v2图纸不一致，用户新增展厅 | 保留版本差异，区分净毛，不静默覆盖；更新状态与日志；受影响面积/交通/结构验证标过期；无需重做无关历史研究 |
| T09 图像误导 | 效果图有楼梯、平剖面没有；用户说图好看就定了 | 指出图纸不一致，生成图不能证明可达；提出补设计或修图；关键选项由用户确认，不以审美认可当技术通过 |
| T10 跳过与恢复 | 用户跳过策划先概念，之后补任务书要求回到定量 | 记录理由、风险、探索边界；补资料后回阶段3核对，并复查受影响4/5；不把跳过标验证通过，不阻塞无依赖探索 |

## 记录格式

测试日期/Skill版本/模型与可用工具/输入版本/实际输出位置/逐项通过失败/失败原因/最小修复/回归结果。禁止把格式验证或本文件存在当成行为测试通过。
